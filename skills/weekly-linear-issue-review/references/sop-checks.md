# SOP Checks

Review active, non-archived Linear issues in:

- `Backlog`
- `Todo`
- `In Progress`
- `In Review`

Check for:

- missing type label: exactly one of `Bug`, `Feature`, `Improvement`, `Chore`, `Spike`
- more than one type label
- `Todo`, `In Progress`, or `In Review` issue without an owner
- `Todo` issue without priority
- `Todo`, `In Progress`, or `In Review` issue without a clear Definition of done
- `Todo`, `In Progress`, or `In Review` issue without Acceptance criteria
- Spike without question, timebox, or output
- activity-style titles like `check`, `look into`, `investigate`, `research`, `work on`
- more than three `In Progress` issues for one owner

Use gentle language:

- `needs_fix`: objective field or status-readiness issue
- `should_improve`: issue is usable but could be easier to verify
- `gentle_suggestion`: subjective wording or scope suggestion

Avoid language like violation, non-compliant, wrong, invalid, bad issue, or failed.
